# smart-todo-srs
# Техническое задание для приложения "Менеджер паролей"

## 📋 О проекте
Приложение "Менеджер паролей" - безопасная система для хранения и управления учетными данными с шифрованием и удобной организацией паролей.

## 🗃️ Структура базы данных

### Основные сущности
- **Пользователи** - управление аккаунтами и мастер-паролями
- **Учетные записи** - безопасное хранение паролей
- **Категории** - организация паролей по группам
- **История паролей** - отслеживание изменений
- **Настройки безопасности** - индивидуальные параметры защиты

## 🎯 Ключевые возможности

### Безопасность
- Шифрование паролей перед сохранением
- Мастер-пароль для доступа к базе
- История изменений паролей
- Гибкие настройки безопасности

### Организация
- Категории для группировки учетных записей
- Быстрый поиск по названиям и URL
- Избранные записи для быстрого доступа
- Отслеживание времени последнего доступа

### Удобство
- Генератор безопасных паролей
- Адаптивный интерфейс
- Синхронизация между устройствами
- Экспорт данных в защищенном формате

## 🗄️ Нормализация базы данных

База данных нормализована до **3NF** (Третьей нормальной формы) с устранением:

- ✅ **Избыточности данных** - минимизация дублирования
- ✅ **Аномалий обновления** - согласованность изменений  
- ✅ **Аномалий удаления** - сохранение целостности данных
- ✅ **Аномалий вставки** - возможность добавления без конфликтов

## 📊 Тестовые данные
Включены реалистичные тестовые данные для 3 пользователей с:

- Разнообразными категориями (Работа, Соцсети, Финансы)
- Различными типами учетных записей
- Историей изменений паролей
- Индивидуальными настройками безопасности

## 🔧 Технологии

- База данных: MySQL 8.0+
- Нормализация: 3NF с контролируемой денормализацией
- Безопасность: Хэширование паролей, шифрование данных
- Оптимизация: Составные индексы, стратегия запросов
