# Процесс нормализации базы данных

## Нормализация до 1NF
- Решено: Все атрибуты атомарны
- Изменения: Категории вынесены в отдельную таблицу

## Нормализация до 2NF
- Решено: Устранены частичные зависимости
- Изменения: Данные пользователей и проектов вынесены в отдельные таблицы

## Нормализация до 3NF
- Решено: Устранены транзитивные зависимости
- Результат: Каждая таблица содержит только атрибуты, зависящие от её PK
