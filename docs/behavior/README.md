# Диаграммы поведения системы
## Use Case Диаграмма
Описание основных сценариев использования приложения "Менеджер паролей"

### Акторы:
-**Пользователь** - основной пользователь системы
-**Администратор** - мониторинг безопасности и управление системой

### Основные Use Cases:
- Добавление новой учетной записи
- Доступ к защищенной учетной записи
- Фильтрация учетных записей по категориям

## Диаграммы последовательности

### 1. Добавление новой учетной записи
Обеспечивает безопасное сохранение новых учетных данных.

### 2. Доступ к защищенной учетной записи
Обеспечивает безопасный доступ к конфиденциальным данным.

### 3. Фильтрация учетных записей по категориям
Эффективная организация и поиск данных.

### 4. Комплексный бизнес-процесс управления паролями
Полный сценарий работы приложения.

## Используемые инструменты
- **PlantUML** - для кодового представления диаграмм
- **draw.io** - для визуального редактирования
